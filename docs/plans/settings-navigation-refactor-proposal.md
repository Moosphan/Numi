# 「我的」功能与设置页重构方案（待确认）

**状态**：方案确认中，不包含代码改动  
**适用范围**：底部「我的」页中“App 功能”及“设置”入口的重组；不改变任一功能的业务规则、会员限制或已有数据。

## 1. 重构目标

当前页面把高频业务入口、低频设置项和高级工具平铺在同一个长列表中。用户必须从十余个同权重的条目里逐项扫描，难以判断“功能在哪里”和“设置在哪里”。

本次重构将一级页收敛为六个分类入口：

1. 功能扩展
2. 数据管理
3. 外观设置
4. 安全中心
5. 通知管理
6. AI 实验室

目标是让一级页只承担“发现与导航”，二级页才承载具体功能；同时保留已有入口的功能、当前配置、访问权限与页面状态。

## 3. 一级页规格

### 页面目的

让用户用一次扫视定位功能类别，而不是在长清单内寻找单个功能。一级页不展示具体业务操作行。

### 页面结构

1. 保留现有的个人/会员状态区域；其位置位于页面顶部，但视觉高度控制在一张紧凑卡片内。
2. 标题使用“功能与设置”；不再把“App 功能”和“设置”拆成两个连续长列表。
3. 使用 **单列瀑布列表** 展示六个入口；每行均包含图标、标题、1 行功能摘要、可选状态信息和右侧导航箭头。
4. 页面底部保留现有 Tab Bar 和“记一笔”悬浮操作，不让新宫格遮挡主记账入口。

### 分类卡片定义

| 分类 | 图标建议 | 功能说明 |
| --- | --- | --- | --- |
| 功能扩展 | `puzzlepiece.extension` | 预算、计划与效率工具 |
| 数据管理 | `externaldrive` | 账户、账本、导入与备份 |
| 外观设置 | `paintpalette` | 主题、语言与显示 |
| 安全中心 | `lock.shield` | 隐私锁与金额保护 |
| 通知管理 | `bell.badge` | 订阅与分期提醒 |
| AI 实验室 | `sparkles` | 智能记账与快捷指令 |

### 视觉与排版规则

- 页面背景沿用现有浅色页面底；卡片使用现有 `surfaceCard`，不引入新的重阴影或玻璃效果。
- 列表行圆角建议 16pt，行间距 12pt，左右页边距 20pt；单行高度约 64pt，保证默认字号下紧凑、动态字体放大后仍可读。
- 每张卡片只使用一个低饱和图标底色；标题 16pt semibold，摘要 12–13pt，最多两行。
- 首页副标题只解释入口包含的功能，不展示账户数量、当前语言或安全开关状态等动态数据。
- 六张卡片都采用完整可点击区域；按下态降低不透明度或轻微缩放，不使用仅右侧箭头可点的行为。

### 一级页不再出现的内容

- 不直接列出“资产、预算、订阅与分期、标签和账本”等具体功能行。
- 不在一级页放置开关、语言选择器、提醒天数选择器或 AI Key 表单。
- 不把导入、恢复、备份等可能产生风险的操作暴露在一级页。

## 4. 二级页规格与功能归属

### 4.1 功能扩展

**定位**：日常记账之外的规划、效率与页面定制工具。

| 排序 | 入口 | 二级页内表现 | 辅助信息 |
| --- | --- | --- | --- |
| 1 | 编辑我的页面 | 进入页面布局与模块显隐设置 | 显示“已显示 X 个模块” |
| 2 | 预算 | 保持现有预算总览入口 | 显示本周期预算状态 |
| 3 | 订阅与分期 | 保持计划管理入口 | 显示待处理/进行中数量 |
| 4 | 存钱计划 | 保持计划入口或新建入口 | 显示进行中计划数量 |
| 5 | 记账模板 | 模板列表及管理 | 显示模板数量 |
| 6 | 报销记录 | 报销列表与筛选 | 有待报销时标注数量 |
| 7 | 搜索与批量编辑 | 高级检索及批量处理 | 标记为“高级工具” |
| 8 | 计划设置 | 未来支出预览范围：30 / 90 / 365 天 | 显示当前范围；仅影响预览，不创建交易 |
| 9 | 订阅扣费需确认 | 到期订阅是否先等待用户确认再记账 | 开启 / 自动记账 |

计划设置从计划页移入本页，作为独立分组置于订阅与分期之后。其中包含两个全局偏好：

- **未来支出预览范围**：30 / 90 / 365 天，继续使用同一个持久化值与 Pro 权限判断；范围切换只更新预览区间，不创建、修改或删除订阅、分期或交易。
- **订阅扣费需确认**：开启后，到期订阅不自动记账，必须由用户确认后才会生成记录；关闭后沿用原来的自动记账行为。迁移后继续使用既有 `app.subscription.requiresConfirmation` 配置值，不改变已到期订阅的状态或处理逻辑。

订阅和分期新增/编辑表单中的“扣费设置”“分期设置”仍留在各自表单内，因为这些是单个计划的必填业务字段（周期、账户、首期日、期数等），并非全局设置。

说明：这是业务能力集合，不放置数据迁移、安全或视觉偏好。

### 4.2 数据管理

**定位**：所有影响账户、账本、数据归档、迁移和同步的管理动作集中在这里。

| 分组 | 入口 | 辅助信息 |
| --- | --- | --- |
| 账务基础 | 资产与账户 | 账户数量、资产总额遵循金额隐藏设置 |
| 账务基础 | 标签、分类与账本 | 可拆为两个连续行，分别进入既有管理页 |
| 账务基础 | 多币种与汇率 | 当前默认币种 |
| 导入导出 | 账单导入与导出 | CSV / JSON 格式提示 |
| 数据保护 | 本地备份与恢复 | 最近备份时间或“未备份” |
| 数据保护 | iCloud 同步 | 当前同步状态 |

风险动作（导入、恢复、覆盖同步）必须维持既有确认、恢复点和错误提示流程；入口迁移不降低确认级别。

### 4.3 外观设置

**定位**：只处理界面视觉和阅读方式，不混入账户或隐私数据管理。

| 入口 | 二级页内表现 | 辅助信息 |
| --- | --- | --- |
| 主题与深浅色 | 进入主题选择页 | 当前主题 |
| 显示语言 | 保留现有语言底部弹层 | 当前语言名称 |

“隐藏金额”保留在安全中心，因为它首先是防旁窥功能；若未来要提供纯显示密度、字号等偏好，可增加“阅读与显示”分组。

### 4.4 安全中心

**定位**：让用户在一个页面完成所有本地隐私保护设置。

| 排序 | 入口 / 控件 | 交互 |
| --- | --- | --- |
| 1 | 隐私锁 | 保留开关；开启后展示解锁方式 |
| 2 | 解锁方式 | 仅隐私锁开启时显示，进入选择页或弹层 |
| 3 | 修改密码 | 仅密码模式或混合模式显示 |
| 4 | 自动模糊 | 保留开关与简短说明 |
| 5 | 隐藏金额 | 保留开关与简短说明 |

页面顶部增加简洁安全状态摘要：未开启时提示“建议开启隐私锁”，开启时提示当前保护方式。金额隐藏状态不显示真实资产数值。

### 4.5 通知管理

**定位**：统一管理来自计划功能的提醒偏好，避免用户在订阅和分期页反复寻找全局提醒设置。

| 入口 | 交互 | 文案规则 |
| --- | --- | --- |
| 订阅扣费提醒 | 选择提前 0 / 1 / 3 / 7 天 | 显示当前选择，如“提前 1 天” |
| 分期还款提醒 | 选择提前 0 / 1 / 3 / 7 天 | 显示当前选择，如“提前 3 天” |

若系统通知权限被拒绝，页面顶部展示说明卡和“前往系统设置”操作；已配置的提醒天数仍可编辑，但明确提示不会送达系统通知。

### 4.6 AI 实验室

**定位**：容纳可选、需用户授权或仍在演进的智能能力；不与基础记账入口混排。

| 入口 | 二级页内表现 | 状态 |
| --- | --- | --- |
| 智能记账与 AI 服务 | 进入供应商、API Key 与连通性测试配置 | 已配置服务商 / 待配置 |
| Siri / 快捷指令记账 | 进入使用说明和配置状态 | 可用 / 需先配置 AI |

API Key 不在列表副标题中暴露任何字符。保留当前会员能力闸口、服务商披露、Key 测试、失败状态和快捷指令的所有逻辑。

## 5. 导航与交互原则

- 一级分类卡片使用 push 导航进入二级页；返回后保留一级页原来的滚动位置。
- 二级页使用标准大标题导航栏和清晰返回按钮；危险操作进入三级页或弹出确认，不在二级页直接执行。
- 既有深链接、自动化测试标识和外部跳转应继续指向原始具体功能页；仅新增“分类页”作为上游入口，不破坏旧路径。
- 有进行中状态的行显示数量或状态摘要，不显示无意义的“>”以外信息；无状态时只保留箭头。
- 免费 / Pro 限制保持在点入具体功能时触发，分类卡不因一个子功能受限而整体锁定。

## 6. 状态与边界

| 场景 | 期望表现 |
| --- | --- |
| 新用户，无任何计划/模板/账户 | 分类页照常展示，具体二级页给出空状态和下一步操作 |
| 开启隐藏金额 | 一级与数据管理页不展示资产金额；只可显示账户数量 |
| 未开启隐私锁 | 安全中心显示建议和开启入口，不制造阻断弹窗 |
| 通知权限被拒绝 | 通知管理明确告知原因，并提供系统设置跳转 |
| AI 未配置 Key | AI 实验室显示“待配置”，可进入说明与配置；不暴露 Key |
| iCloud 同步失败 | 数据管理显示失败状态和可恢复的处理入口，不在一级页输出冗长错误 |
| 动态字体 / 小屏 | 宫格卡片内容允许摘要截断；标题不截断，必要时由两列切换为单列 |
| 多语言切换 | 分类名、摘要、状态、无障碍标签均实时更新；不缓存最终展示文案 |

## 7. 实施边界与验收标准

### 本轮包含

- 新建六个分类二级页及一级分类宫格。
- 将现有入口按本方案重新路由，复用既有业务页和数据服务。
- 将计划页的全局“未来支出预览范围”迁移至“功能扩展 → 计划设置”；计划页保留预览内容，不再承载范围选择器。
- 将计划页“订阅与分期”区域中的全局“扣费需确认”开关迁移至“功能扩展 → 计划设置”；订阅列表保留状态与操作，不再承载该全局开关。
- 为分类、状态摘要和空状态补齐简中、繁中、英文、日文文案。
- 更新无障碍标签和 UI 自动化定位；保留已有具体功能的稳定标识。

### 本轮不包含

- 改写预算、订阅、同步、备份、AI 或会员的业务规则；计划表单内的单项业务字段也不迁移。
- 新增云端服务、通知种类或 AI 提供商。
- 改变底部导航结构和“记一笔”浮动按钮的行为。

### 验收清单

- 一级页仅出现六个分类入口，不再出现十余条功能平铺。
- 截图中列出的 12 项均能通过一个明确分类进入，且无遗漏、无重复主入口。
- 任意既有功能的可达性、会员限制、确认流程和已保存配置保持不变。
- 计划页预览范围迁移后，用户已保存的 30 / 90 / 365 天选择保持生效，且切换范围不会写入交易数据。
- 扣费确认开关迁移后，原有开关值保持生效：开启时到期订阅必须手动确认，关闭时维持自动记账；迁移本身不补记或撤销任何记录。
- 小屏、200% 动态字体、深浅色、隐藏金额和四语言下没有截断关键标题、颜色单独传意或敏感值泄漏。
- 从二级页返回一级页时，滚动位置与状态摘要正确恢复。

## 8. 需要确认的产品决策

已确认：采用“功能与设置”作为一级页标题，并将六类入口做成 2 列宫格；资产归入“数据管理”；“编辑我的页面”归入“功能扩展”；会员状态卡继续固定在一级页顶部并压缩为不超过约 96pt 高度。

已确认：计划页的全局设置项迁移到“功能扩展 → 计划设置”，包括“未来支出预览范围”和“订阅扣费需确认”。实施时将严格区分全局偏好和表单业务字段，避免将订阅、分期的必要编辑项错误移出表单。

确认以上四点后，即可进入界面实现与截图验收阶段。
